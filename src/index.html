Requests include bots, assets, errors and API traffic visible to Cloudflare. Browser views use a separate dataset. Missing history stays missing.

Collection health & coverage

HTTP request totals cover traffic proxied through this Cloudflare zone. DNS-only sites bypass its request analytics. Web Analytics depends on a working browser beacon and can miss blocked scripts. Adaptive breakdowns can be estimates. No dataset here is a raw log of every individual hit.

Retention, counting and archive details

All dates use UTC, including yesterday. Daily unique IP counts are not people and are not added across days. Totals from different data sources are never added together. Detailed rows may not exactly reconcile with daily summaries because Cloudflare datasets have different sampling and counting behaviour.

Queries do not filter out bots, errors or static files. Country and status maps retain all returned entries. Some advanced fields require a different Cloudflare plan. Missing, restricted and failed datasets remain clearly marked. Paths exclude query strings and common identifying patterns are redacted.

Git retains the archive while this repository and its history are retained. Clone it periodically for an independent backup. Historical detail that Cloudflare has already deleted cannot be recovered from this API.

Network transparency

Filters, charts, searches and exports run in your browser. This page loads a public JSON snapshot from the same site and the official shared Mightora components, styles, logos and js-yaml from jsDelivr and GitHub. No Cloudflare API token is sent to this browser. No advertising or visitor analytics script is included by this application. The shared header may remember your theme using localStorage.

Press F12 → Network → Preserve log, then reload to inspect requests. Resource Timing may omit requests or details; this monitor is not a security audit. The offline edition embeds all required resources and blocks application network connections.
